# Исходный код лабораторной работы (2022)

Первая версия, из которой вырос проект. Сохранена без изменений.

- `bagging_*.py` — нейросеть `my_NN`, бутстрэп-выборки и голосование большинством.
- `boosting_*.py` — та же сеть и бустинг в стиле AdaBoost: выборка по весам примеров,
  ошибка модели, её вес и перевзвешивание примеров.

Отличия актуальной версии в `src/nn_ensembles`:

- дубли в данных удаляются до разбиения на обучение и тест;
- веса примеров передаются прямо в функцию потерь, а не через выборку с возвращением;
- итоговое голосование AdaBoost взвешено по качеству моделей;
- фиксированный `random_state`, тесты и кросс-валидация вместо одного разбиения.
